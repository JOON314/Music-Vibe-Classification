**요약**
- 8개 피처(auditory spectrum L1, 대역 에너지 2개, flux, MFCC 1·4, sharpness, slope)는 플레이리스트 곡의 **93~100%가 DEAM 범위 밖**.
  `audspec_lengthL1norm`은 평균이 약 2,200σ 떨어져 있음 → 곡의 차이가 아니라 **계산 방식·단위(스케일) 차이**.
- 곡별 RMS z-score: 플레이리스트 중앙값 **444**, DEAM 중앙값 0.74 (DEAM 99% 분위 2.66).
- 결과: 플레이리스트 원시 예측값의 표준편차가 19~59 (DEAM 척도는 1~9) → 모델이 학습 범위 밖으로 크게 외삽.
  이 때문에 학습을 다시 할 때마다 Arousal 순위가 거의 뒤집힘. `scale_to_10`이 이를 0~10에 눌러 담아 겉보기엔 정상처럼 보였음.

**해결 방안**
- (권장) 2단계를 실제 openSMILE(`opensmile` 파이썬 패키지, ComParE_2016 LLD)로 교체. 24개 피처가 모두 같은 이름으로 있음
  (MFCC만 `mfcc_sma[k]` ↔ `pcm_fftMag_mfcc_sma[k]` 이름 차이). DEAM과 같은 도구라 시프트가 거의 사라질 것으로 예상.
  맥(Apple Silicon)에서 설치·동작 확인함. 곡 2개로 실제 분포를 확인한 뒤 적용.
- (대안) librosa 피처를 DEAM 분포에 맞춰 보정 — 근거가 약해 비추천.

## 2. `scale_to_10` (플레이리스트 내 min-max) vs DEAM 원래 척도

| | 현재: min-max 0~10 | 대안: DEAM 척도(1~9) 그대로 |
|---|---|---|
| 의미 | 이 플레이리스트 안에서의 **상대 순위** | 곡 자체의 **절대** 분위기 |
| 같은 곡의 결과 | 같이 넣은 곡에 따라 바뀜 | 항상 같음 |
| 강제 극단값 | 최소곡은 항상 0(→ -1), 최대곡은 항상 10(→ +1) | 없음 |
| 1곡짜리 플레이리스트 | 항상 0 → **무조건 "차분한 & 우울한"** | 정상 |
| 2곡짜리 | 무조건 한 곡은 -1, 한 곡은 +1 | 정상 |
| `(x-5)/5`, 임계값 ±0.2 와의 관계 | 원래 1~9 척도용으로 설계된 변환을 0~10에 적용 | 설계 의도와 일치 |
| 도메인 시프트가 있는 지금 | 이상한 원시값을 가려줌 | 원시값이 1~9를 크게 벗어나 대부분 ±1로 잘림 |

DEAM 라벨에 같은 임계값을 적용하면: Valence 담담한 57% / 우울한 25% / 밝은 18%, Arousal 포근한 51% / 차분한 30% / 활기찬 19%.
→ **권장: openSMILE로 시프트를 해결한 뒤 DEAM 척도 그대로 사용.** 시프트를 그대로 둔다면 지금의 min-max가 차라리 나음.

## 4. openSMILE 교체 후 16곡 중 15곡이 '포근한'으로 나온 원인 조사

DEAM 척도로 바꾸자 Arousal이 4.69~6.16(표준편차 0.37)에 몰려 15곡이 '포근한'(4~6)이 됐다. 코드 버그는 없었고 원인은 두 가지였다.

### 4-1. 모델: 예측이 평균 쪽으로 압축됨
저장된 Fold 모델로 각 Fold의 검증 곡(학습에 안 쓴 곡)을 예측(OOF)해 DEAM 라벨과 비교:

| | 라벨 표준편차 | OOF 예측 표준편차 | 상관 | 라벨 분포 | 예측 분포 (±0.2 기준) |
|---|---|---|---|---|---|
| Valence | 1.17 | 0.80 | 0.62 | 담담한 57% / 우울한 25% / 밝은 18% | 담담한 79% / 우울한 14% / 밝은 7% |
| Arousal | 1.28 | 0.91 | 0.66 | 포근한 51% / 차분한 30% / 활기찬 19% | 포근한 70% / 차분한 21% / 활기찬 9% |

실제 '활기찬' 곡의 73%가 '포근한'으로 예측됨. 회귀 모델(R² 0.4 수준)이 평균 쪽으로 당기는 성질 + ±0.2(=4~6) 구간이 원래 라벨의 절반을 덮는 넓은 구간이라서.

### 4-2. 피처: 플레이리스트 음원이 DEAM보다 훨씬 큼
openSMILE 피처 중 에너지 계열만 크게 치우침 (RMS 에너지 +2.4σ, auditory spectrum +2.3σ, 대역 에너지 +1.8~3.4σ, flux +2.6σ, slope −2.6σ).
RMS 중앙값 비율 2.67배 → 단순 gain이라면 파워 계열은 2.67² ≈ 7.2배여야 하는데 대역 에너지 8.1·7.4배, slope 7.3배로 일치 →
**녹음 음량 차이(약 +8.5dB)**. 16곡 모두 DEAM 중앙값의 1.7~3.7배. (요즘 음원의 마스터링 음량 vs DEAM의 무료 음원 아카이브 MP3 클립)

### 4-3. 실험 (16곡을 다시 받아 같은 모델로 예측)

| 조건 | 곡별 RMS z 중앙값 | Arousal 예측 표준편차 | Arousal 분포 (±0.2 기준) |
|---|---|---|---|
| A. 전곡 그대로 | 1.37 | 0.37 | 포근한 15 / 활기찬 1 |
| B. 전곡 × 공통 gain 1/2.67 | 0.51 | 0.70 | 포근한 13 / 활기찬 2 / 차분한 1 |
| C. 가운데 45초만 (DEAM 클립 길이) | 1.54 | 0.34 | 포근한 16 |
| D. B + C | 0.56 | 0.71 | 포근한 11 / 차분한 3 / 활기찬 2 |
| **E. 곡별 음량을 DEAM 중앙값에 맞춤** | **0.50** | **0.62** | 포근한 14 / 활기찬 1 / 차분한 1 |
| **E + 보정 임계값 (채택)** | 0.50 | 0.62 | **포근한 8 / 활기찬 6 / 차분한 2** |

- 45초 구간 사용은 효과 없음 → 채택 안 함. 공통 gain(B)은 이 플레이리스트로 계산한 값이라 순환 논리 → 곡별 정규화(E) 채택.
- 보정 임계값: DEAM OOF 예측을 3등분하는 값 (Valence 4.56 / 5.34, Arousal 4.40 / 5.35). 학습 때 계산해 `models/train_meta.json`에 저장.
  모델 출력 분포 기준의 고정값이라 플레이리스트와 무관한 절대 기준.
- 채택 후 순서: 가장 차분 seasons(3.99)·파란달팽이(4.26) … 가장 활기 곰팡이(6.04)·노세노세(5.90)·돌연변이(5.89)·완공(5.81).
